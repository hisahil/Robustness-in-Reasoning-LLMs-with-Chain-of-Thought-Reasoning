# Progress and next steps

## Already in this repository

The code covers baseline generation, controlled interventions, paired immediate answers and continued reasoning, and grading. Automated tests cover extraction, interventions, configuration, and evaluation.

Two earlier pilots are included as readable examples:

- 50 paired MATH-500 dialogues from a DeepSeek-R1-Distill-Qwen-7B pilot, spread across problems and the three intervention types.
- A short cross-model check in which eleven models each produced a baseline, an off-topic insertion, and both answers for one MATH-500 problem. One GLM continued-reasoning output has no gradable answer.

## Next

Broader model and task coverage, additional controls, and more systematic robustness checks. A more extensive version, with more code and results, may be published later.
